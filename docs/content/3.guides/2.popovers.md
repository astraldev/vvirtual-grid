Click an item to open a native popover under it. Scroll the grid and the popover follows the item, even after the item leaves the DOM.

::popover-demo
::

The demo listens to clicks on the grid, finds the index under the pointer, and positions the popover from that index.

```vue
<script setup>
import { ref, useTemplateRef } from "vue";
import { VirtualGrid } from "vvirtual-grid/vue";
import { getItemIndex, getItemViewportRect } from "vvirtual-grid/primitives";

const grid = useTemplateRef("grid"); // the <VirtualGrid> instance
const popover = useTemplateRef("popover");
const anchored = ref(-1);

// reused on every call, so scrolling allocates nothing
const rectArgs = { root: null, index: -1, layout: null, out: { x: 0, y: 0, width: 0, height: 0 } };

function place() {
  rectArgs.root = grid.value.$el;
  rectArgs.index = anchored.value;
  rectArgs.layout = grid.value.measurement;
  if (rectArgs.index < 0 || !rectArgs.layout || !getItemViewportRect(rectArgs)) return;
  const { x, y, height } = rectArgs.out;
  popover.value.style.translate = `${x}px ${y + height}px`;
}

function open(event) {
  anchored.value = getItemIndex({ root: grid.value.$el, target: event.target });
  if (anchored.value === -1) return;
  place();
  popover.value.showPopover();
}
</script>

<template>
  <div class="h-80 overflow-y-auto">
    <VirtualGrid
      ref="grid"
      :length="10000"
      :page-size="40"
      :page-provider="pageProvider"
      @click="open"
      @viewport-scroll="place"
      @layout-change="place"
    >
      <template #default="{ item, index, style }">
        <button :style="style" :data-index="index">{{ item.title }}</button>
      </template>
    </VirtualGrid>
  </div>

  <div ref="popover" popover style="position: fixed; inset: 0 auto auto 0; margin: 0">
    Item {{ anchored }}
  </div>
</template>
```

## Find the item under an event

[`getItemIndex`](/reference/primitives#find-elements) walks from `event.target` up to the grid's child and reads its `data-index`.
One listener on the grid covers every item, so items need no handlers of their own.

The same pattern works for `pointerover`, `focusin` or `contextmenu`. Dispatch your own event from there if other components need it.

```ts
function onFocusIn(event: FocusEvent) {
  const index = getItemIndex({ root: grid.value.$el, target: event.target });
  if (index !== -1) grid.value.$el.dispatchEvent(new CustomEvent("item-focus", { detail: index }));
}
```

## Position from the index

[`getItemViewportRect`](/reference/primitives#compute-positions) returns viewport coordinates for any index.
It reads one element's position, the grid's first child, and computes the rest. Use `position: fixed` on the overlay so those coordinates apply directly.

Call `place()` in three places:

- After opening, for the first position.
- In `onViewportScroll`, because the item moved on screen.
- In `onLayoutChange`, because the column count or item size changed.

The `rectArgs` object is created once. Scrolling calls `place()` on every scroll event without creating objects.

## Hide the overlay when the item is out of view

The rectangle stays valid after the item scrolls out, so the popover moves off screen with it.
To close it instead, compare `rectArgs.out` with the scroll container's bounds in `place()` and call `hidePopover()`.

## Use CSS anchor positioning

Where the browser supports [CSS anchor positioning](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_anchor_positioning), the browser can place the popover while the item is rendered.
Set `anchor-name` on the item's element as it renders, and clear it when it leaves.

```ts
import { createItemTracker } from "vvirtual-grid/primitives";

const track = createItemTracker({
  onBind: (index, element) => {
    element.style.anchorName = index === anchored.value ? "--item" : "";
  },
  onUnbind: (index) => {
    if (index === anchored.value) popover.value.hidePopover();
  },
});
```

```css
[popover] {
  position-anchor: --item;
  top: anchor(bottom);
  left: anchor(left);
}
```

Call `track(grid.value.$el)` from `@render`. The popover closes when its item leaves the DOM, because the anchor element is gone.

The tracker reports changes in what is rendered, not changes to `anchored`. When you anchor an item that is already rendered, set `anchorName` on [`getItemElement({ root, index })`](/reference/primitives#find-elements) yourself.
