On a scroll event that stays within the same rows, the grid compares two numbers and stops.
It recomputes the rendered window only when the first visible row changes.

## Keep callbacks cheap

`onViewportScroll` runs on every scroll event. Read positions there, but create no objects.

```ts
// wrong: getItemViewportRect({ root, index, layout, out: { x: 0, y: 0, width: 0, height: 0 } })
const args = { root: null, index: 0, layout: null, out: { x: 0, y: 0, width: 0, height: 0 } };

function onViewportScroll() {
  args.root = grid.value.$el;
  args.layout = grid.value.measurement;
  if (args.layout) getItemViewportRect(args);
}
```

`getItemViewportRect` reads the layout of one element. Write styles after it, not between two reads, or the browser lays out the page twice.

## Keep items stable

- Items are keyed by index by default. Pass `getKey` to key them by your id, so an element stays with its item when the list changes.
- Keep slot content small. Every rendered item is a component render on each window change.
- When a page arrives and the window has not moved, the grid keeps the same item objects. Items that did not change do not render again.

## Request fewer pages

Set `pageProviderDebounceTime` to 100 or 200 milliseconds for network providers.
Pages the user scrolls past within that time are never requested.

## Import only what you use

The package is marked `"sideEffects": false`, and every export is named.

| Import | Contains |
| :-- | :-- |
| `vvirtual-grid/vue` | The component, the plugin and `createPageProvider`. |
| `vvirtual-grid/primitives` | The [primitives](/reference/primitives) only, with no dependencies. |
| `vvirtual-grid/nuxt` | The Nuxt module. |

A bundle that imports only `VirtualGrid` contains none of the primitives.
