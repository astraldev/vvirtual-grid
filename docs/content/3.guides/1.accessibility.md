The grid renders a flat list of elements and adds no ARIA. Most items are not in the DOM, so a screen reader cannot count them.
Give each rendered item its position and the list's total size.

```vue
<template>
  <VirtualGrid role="list" :length="length" :page-size="40" :page-provider="pageProvider">
    <template #default="{ item, index, style }">
      <div
        :style="style"
        :data-index="index"
        role="listitem"
        :aria-setsize="length"
        :aria-posinset="index + 1"
      >
        {{ item.title }}
      </div>
    </template>

    <template #placeholder="{ index, style }">
      <div
        :style="style"
        :data-index="index"
        role="listitem"
        aria-busy="true"
        :aria-setsize="length"
        :aria-posinset="index + 1"
      />
    </template>
  </VirtualGrid>
</template>
```

A screen reader announces the item at 4200 as "4,200 of 10,000", although only a few dozen items exist in the DOM.

## Pick a role

| Pattern | Roles | Fits the grid's DOM |
| :-- | :-- | :-- |
| List | `list` and `listitem` | Yes, items are direct children. |
| Selectable list | `listbox` and `option` | Yes. Add `aria-selected` on each option. |
| Data grid | `grid`, `row` and `gridcell` | No. `row` elements must wrap the cells, and the grid renders items without rows. |

`aria-posinset` counts from 1. The slot's `index` counts from 0.

## Report rows and columns

For a description that names rows and columns, compute them with [`getItemCellByIndex`](/reference/primitives#compute-rows-and-columns) and [`getGridDimensions`](/reference/primitives#compute-rows-and-columns).

```ts
import { getGridDimensions, getItemCellByIndex } from "vvirtual-grid/primitives";

const grid = useTemplateRef("grid"); // the <VirtualGrid> instance
const cellArgs = { index: 0, layout: null, out: { row: 0, column: 0 } };
const sizeArgs = { length, layout: null, out: { rowCount: 0, columnCount: 0 } };

function describe(index: number) {
  const layout = grid.value.measurement;
  if (!layout) return "";
  cellArgs.index = index;
  cellArgs.layout = sizeArgs.layout = layout;
  const cell = getItemCellByIndex(cellArgs);
  const size = getGridDimensions(sizeArgs);
  return `Row ${cell.row + 1} of ${size.rowCount}, column ${cell.column + 1}`;
}
```

Put the result in `aria-description` or a visually hidden element. These numbers change when the column count changes, so read them again in `onLayoutChange`.

## Move focus with the keyboard

The grid does not handle keys. A roving `tabindex` works with virtualized items.

1. Keep the focused index in a ref, not the focused element.
2. Render `tabindex="0"` on the item whose index matches and `tabindex="-1"` on the rest.
3. On an arrow key, compute the next index with [`getIndexByCell`](/reference/primitives#compute-rows-and-columns), then set `scrollTo` to it.
4. In `onRender`, call [`getItemElement`](/reference/primitives#find-elements) for that index and focus it once it is not `null`.

::warning
Do not point `aria-activedescendant` at an item that is scrolled out. Its element is removed, and the reference breaks. Clear the attribute when `getItemElement` returns `null`.
::
