In this guide you position a floating element next to a grid item with [Floating UI](https://floating-ui.com), including flipping and shifting at the viewport edge.
Floating UI measures its reference element with `getBoundingClientRect()`. A virtual item that scrolled out of the grid has no element to measure.
Floating UI accepts a plain object with a `getBoundingClientRect()` method, called a virtual element. You give it the rectangle the grid computes for the index, so the floating element keeps working when the item is not in the DOM.

::floating-demo
::

In the demo, the popover keeps following the clicked item after you scroll far enough that the item is no longer in the DOM.

## Build the virtual element

The rectangle comes from `getItemRect`. Set `root` to the grid element, so the rectangle holds viewport coordinates, as `getBoundingClientRect()` does. The `rect` field has the same `x`, `y`, `width`, `height`, `top`, `right`, `bottom` and `left` fields as a `DOMRect`.

::steps{level="3"}

### Create the query and the virtual element

Create the query once. The virtual element updates the query, calls `getItemRect`, and returns `query.rect`.
Reusing one query object avoids a new rectangle on every scroll event.
Put the virtual element in a `shallowRef`, because `useFloating` reads its reference from `.value` and a plain object gives it nothing to position against.

```vue
<script setup>
import { ref, shallowRef, useTemplateRef } from "vue";
import { createRectQuery, getItemRect } from "vvirtual-grid/primitives";

const grid = useTemplateRef("grid");
const anchored = ref(-1);
const query = createRectQuery();

const reference = shallowRef({
  getBoundingClientRect() {
    query.root = grid.value.$el;
    query.index = anchored.value;
    query.layout = grid.value.measurement;
    getItemRect(query);
    return query.rect;
  },
});
</script>
```

Render the grid, and set `anchored` to the index of the item the user clicks.

```vue
<template>
  <div class="h-96 overflow-y-auto">
    <VirtualGrid ref="grid" :length="10000" :page-size="40" :page-provider="pageProvider">
      <template #default="{ item, index, style }">
        <button :style="style" :data-index="index" @click="anchored = index">
          {{ item.title }}
        </button>
      </template>
    </VirtualGrid>
  </div>
</template>
```

If `getItemRect` returns `false`, the rectangle keeps its last values. This is acceptable here, because the floating element stays where it was until the grid measures again.

### Position with `useFloating`

With `@floating-ui/vue`, pass the virtual element, the floating element and the options to `useFloating`. Use `strategy: "fixed"`, because the rectangle holds viewport coordinates.

```vue
<script setup>
import { useFloating, offset, flip, shift } from "@floating-ui/vue";

const floating = useTemplateRef("floating");

const { floatingStyles, update } = useFloating(reference, floating, {
  strategy: "fixed",
  placement: "bottom-start",
  middleware: [offset(4), flip(), shift()],
});
</script>

<template>
  <div ref="floating" popover :style="floatingStyles" style="margin: 0; inset: auto">
    Item {{ anchored }}
  </div>
</template>
```

`floatingStyles` sets `position`, `left`, `top` and `transform` on the element. The inline `margin` and `inset` reset what the browser sets on a native `popover`.

### Update on scroll and layout changes

`useFloating` computes the position when the elements change. It does not know that the grid scrolled or that the item size changed.
Call `update()` from the grid's events.

```vue
<template>
  <VirtualGrid
    ref="grid"
    :length="10000"
    :page-size="40"
    :page-provider="pageProvider"
    @viewport-scroll="update"
    @layout-change="update"
  >
    <!-- slots from step 1 -->
  </VirtualGrid>
</template>
```

Also call `update()` right after you change `anchored`, because the index changed but no element did.
Show the popover before you call `update()`. A hidden popover has no size, and Floating UI only treats it as shown in the top layer after `showPopover()`. Replace `@click="anchored = index"` from step 1 with `@click="open(index)"`:

```ts
function open(index) {
  anchored.value = index;
  floating.value.showPopover();
  update();
}
```

### Flip at the edge of the scroll container

By default, `flip()` and `shift()` keep the floating element inside the browser window. A popover sits in the top layer, so the scroll container does not clip it, and Floating UI does not count the container as an edge.
To flip at the container's edge instead, pass the container as `boundary` to both. Add `ref="scroller"` to the scroll container from step 1.

```ts
import { onMounted } from "vue";

const scroller = useTemplateRef("scroller");
const overflow = { boundary: undefined };

onMounted(() => {
  overflow.boundary = scroller.value;
});
```

Then change the `middleware` option from step 2 to `[offset(4), flip(overflow), shift(overflow)]`. Floating UI reads `overflow.boundary` on every update, so one object serves both and no update creates a new one.

### Check that it follows the item

Open the floating element on an item, then scroll far enough that the item leaves the DOM. The element keeps moving with the item's position.
Open it on an item near the bottom edge of the scroll container. `flip()` moves it above the item.

## Use `autoUpdate`

`useFloating` can call `update()` for you through `whileElementsMounted`.

```ts
import { autoUpdate } from "@floating-ui/vue";

useFloating(reference, floating, {
  strategy: "fixed",
  middleware: [offset(4), flip(), shift()],
  whileElementsMounted: autoUpdate,
});
```

`autoUpdate` listens for scrolls on the scroll parents of the reference element. A virtual element has no element, so it has none to listen to. It still listens to the scroll parents of the floating element, so it only sees the grid's scroll container when the floating element sits inside it.
Keep `@viewport-scroll="update"` and `@layout-change="update"` even with `autoUpdate`. The grid emits `viewport-scroll` on every scroll of any parent, and the update reads a fresh rectangle. `autoUpdate` cannot see a change of item size or gap, and `layout-change` reports it.

## Use `@floating-ui/dom` without Vue

`computePosition` takes the same virtual element and returns the coordinates. Pass it `reference.value` and `floating.value`, the virtual element and the floating element from steps 1 and 2, and write the coordinates to the element yourself.

```ts
import { computePosition, offset, flip, shift } from "@floating-ui/dom";

async function place() {
  const { x, y } = await computePosition(reference.value, floating.value, {
    strategy: "fixed",
    placement: "bottom-start",
    middleware: [offset(4), flip(), shift()],
  });
  floating.value.style.translate = `${x}px ${y}px`;
}
```

The element needs `position: fixed; inset: 0 auto auto 0; margin: 0`, so the translation starts at the top left of the window. A native `popover` has `margin: auto` by default, which centers it.
Call `place()` on `viewport-scroll` and `layout-change`, as in step 3, and once right after `showPopover()`.
