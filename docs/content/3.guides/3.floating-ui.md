In this guide you position a floating element next to a grid item with [Floating UI](https://floating-ui.com), including flipping and shifting at the viewport edge.
Floating UI measures its reference element with `getBoundingClientRect()`. A virtual item that scrolled out of the grid has no element to measure.
Floating UI accepts a plain object with a `getBoundingClientRect()` method, called a virtual element. You give it the rectangle the grid computes for the index, so the floating element keeps working when the item is not in the DOM.

## Build the virtual element

The rectangle comes from `getItemRect`. Set `root` to the grid element, so the rectangle holds viewport coordinates, as `getBoundingClientRect()` does. The `rect` field has the same `x`, `y`, `width`, `height`, `top`, `right`, `bottom` and `left` fields as a `DOMRect`.

::steps{level="3"}

### Create the query and the virtual element

Create the query once. The virtual element updates the query, calls `getItemRect`, and returns `query.rect`.
Reusing one query object avoids a new rectangle on every scroll event.

```vue
<script setup>
import { ref, useTemplateRef } from "vue";
import { createRectQuery, getItemRect } from "vvirtual-grid/primitives";

const grid = useTemplateRef("grid");
const anchored = ref(-1);
const query = createRectQuery();

const reference = {
  getBoundingClientRect() {
    query.root = grid.value.$el;
    query.index = anchored.value;
    query.layout = grid.value.measurement;
    getItemRect(query);
    return query.rect;
  },
};
</script>

<template>
  <div class="h-96 overflow-y-auto">
    <VirtualGrid ref="grid" :length="10000" :page-size="40" :page-provider="pageProvider">
      <template #default="{ item, index, style }">
        <button :style="style" :data-index="index" @click="anchored = index">
          {{ item.title }}
        </button>
      </template>
    </VirtualGrid>
  </div>
</template>
```

If `getItemRect` returns `false`, the rectangle keeps its last values. This is acceptable here, because the floating element stays where it was until the grid measures again.

### Position with `useFloating`

With `@floating-ui/vue`, pass the virtual element, the floating element and the options to `useFloating`. Use `strategy: "fixed"`, because the rectangle holds viewport coordinates.

```vue
<script setup>
import { useFloating, offset, flip, shift } from "@floating-ui/vue";

const floating = useTemplateRef("floating");

const { floatingStyles, update } = useFloating(reference, floating, {
  strategy: "fixed",
  placement: "bottom-start",
  middleware: [offset(4), flip(), shift()],
});
</script>

<template>
  <div ref="floating" popover :style="floatingStyles" style="margin: 0; inset: auto">
    Item {{ anchored }}
  </div>
</template>
```

`floatingStyles` sets `position`, `left`, `top` and `transform` on the element. The inline `margin` and `inset` reset what the browser sets on a native `popover`. Call `showPopover()` when you open it, as in the [popovers guide](/guides/popovers).

### Update on scroll and layout changes

`useFloating` computes the position when the elements change. It does not know that the grid scrolled or that the item size changed.
Call `update()` from the grid's events.

```vue
<template>
  <VirtualGrid
    ref="grid"
    :length="10000"
    :page-size="40"
    :page-provider="pageProvider"
    @viewport-scroll="update"
    @layout-change="update"
  >
    <!-- slots from step 1 -->
  </VirtualGrid>
</template>
```

Also call `update()` right after you change `anchored`, because the index changed but no element did.

### Check that it follows the item

Open the floating element on an item, then scroll far enough that the item leaves the DOM. The element keeps moving with the item's position.
Open it on an item at the bottom edge of the scroll container. `flip()` moves it above the item, and `shift()` keeps it inside the viewport horizontally.

## Use `autoUpdate`

`useFloating` can call `update()` for you through `whileElementsMounted`.

```ts
import { autoUpdate } from "@floating-ui/vue";

useFloating(reference, floating, {
  strategy: "fixed",
  middleware: [offset(4), flip(), shift()],
  whileElementsMounted: autoUpdate,
});
```

`autoUpdate` listens for scrolls on the scroll parents of the reference element. A virtual element has no element, so it has no parents to listen to.
Keep `@viewport-scroll="update"` even with `autoUpdate`. The grid emits that event on every scroll of any parent, and the update reads a fresh rectangle.

## Use `@floating-ui/dom` without Vue

`computePosition` takes the same virtual element and returns the coordinates. Write them to the element yourself.

```ts
import { computePosition, offset, flip, shift } from "@floating-ui/dom";

async function place() {
  const { x, y } = await computePosition(reference, floatingElement, {
    strategy: "fixed",
    placement: "bottom-start",
    middleware: [offset(4), flip(), shift()],
  });
  floatingElement.style.translate = `${x}px ${y}px`;
}
```

Call `place()` on `viewport-scroll` and `layout-change`, as in step 3, and once when the element opens.
