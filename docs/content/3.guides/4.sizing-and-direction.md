The grid places items with arithmetic, so it needs to know how big one item is. It cannot read the size of items that are not rendered. In this guide you give the grid a probe that sets the item size, make the size change with the screen width, and then turn the grid sideways.

Every item in the grid has the same width and height. These are the size of the probe.

## Give the grid an item size

::steps
### Put the grid in a scroll container

Wrap `<VirtualGrid>` in an element that scrolls and has a fixed height. Do not set `overflow` or a fixed height on `<VirtualGrid>` itself. After computing, the grid sets its own height, overriding whatever you set, and the page scrolls instead of the grid.

### Make the grid a CSS grid

Add `grid` and column tracks to the class of `<VirtualGrid>`. The grid reads the column count from the computed `grid-template-columns`, and the gaps from `column-gap` and `row-gap`.

### Add a probe

Add a `probe` slot that holds one empty element with the same classes as your items. The grid renders the probe hidden and measures it with a `ResizeObserver`. Every item then gets the probe's width and height.

```vue
<script setup>
import { useTemplateRef } from "vue";

const grid = useTemplateRef("grid");
const length = 10_000;
const pageProvider = (page, pageSize) =>
  Array.from({ length: pageSize }, (_, i) => ({ title: `Item ${page * pageSize + i}` }));
</script>

<template>
  <div class="h-[600px] overflow-y-auto">
    <VirtualGrid
      ref="grid"
      :length="length"
      :page-size="40"
      :page-provider="pageProvider"
      class="grid grid-cols-[repeat(auto-fill,minmax(160px,1fr))] gap-4"
    >
      <template #default="{ item, style }">
        <div :style="style" class="h-40 md:h-64">{{ item.title }}</div>
      </template>

      <template #probe>
        <div class="h-40 md:h-64" />
      </template>
    </VirtualGrid>
  </div>
</template>
```

### Check the size

Open the page and inspect an item. It is 160px tall below the `md` breakpoint and 256px tall above it. Resize the window across the breakpoint. The grid measures the probe again, moves the items to their new positions, and emits `layout-change`.
::

::warning
Items that are taller or shorter than the probe do not change the layout. The grid places them at the probe's height, so taller items overlap the next row and shorter ones leave gaps.
::

If you leave out the probe, set `grid-auto-rows` on the grid and the grid measures the height from there.

## Scroll sideways

The grid scrolls sideways when you set `grid-auto-flow: column` and a fixed number of rows. The grid then sets its `width` to the width of the whole list, and the parent scrolls on the x axis.

::steps
### Put the grid in a horizontally scrolling container

Use an element with `overflow-x: auto`. Give it a height, because the rows share it.

### Set the flow and the rows

Add `grid-flow-col` and `grid-rows-2` to the grid, and fix the width of each column with `auto-cols-[200px]`. Use a probe with the same width as a column.

```vue
<script setup>
import { useTemplateRef } from "vue";

const grid = useTemplateRef("grid");
const length = 10_000;
const pageProvider = (page, pageSize) =>
  Array.from({ length: pageSize }, (_, i) => ({ title: `Item ${page * pageSize + i}` }));
</script>

<template>
  <div class="h-[320px] overflow-x-auto">
    <VirtualGrid
      ref="grid"
      :length="length"
      :page-size="40"
      :page-provider="pageProvider"
      class="grid h-full grid-flow-col grid-rows-2 auto-cols-[200px] gap-4"
    >
      <template #default="{ item, style }">
        <div :style="style" class="h-full w-[200px]">{{ item.title }}</div>
      </template>

      <template #probe>
        <div class="w-[200px]" />
      </template>
    </VirtualGrid>
  </div>
</template>
```

### Check the order

Items 0 and 1 fill the first column, top to bottom. Item 2 starts the second column. [`getItemCell`](/reference/primitives) returns the same order, and `getIndexByCell` maps it back.
::

## Scroll to an item

Set `scrollTo` to an index and the grid scrolls its scroll parent to that item, using `scrollBehavior`. With `respectScrollToOnResize` on, the grid scrolls to that index again after each resize, so a change in column count does not lose the item.
