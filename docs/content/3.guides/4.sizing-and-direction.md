Every item in the grid has the same width and height. The size can change between breakpoints.

```vue
<template>
  <div class="h-[600px] overflow-y-auto">
    <VirtualGrid
      :length="length"
      :page-size="40"
      :page-provider="pageProvider"
      class="grid grid-cols-[repeat(auto-fill,minmax(160px,1fr))] gap-4"
    >
      <template #default="{ item, style }">
        <div :style="style" class="h-40 md:h-64">{{ item.title }}</div>
      </template>

      <template #probe>
        <div class="h-40 md:h-64" />
      </template>
    </VirtualGrid>
  </div>
</template>
```

Items are 160px tall below the `md` breakpoint and 256px above it. The probe uses the same classes, so the grid measures the size in effect.

## Measure items with the probe

The grid renders the `probe` slot hidden and watches its size with a `ResizeObserver`.
It measures again when the grid resizes, and then calls [`onLayoutChange`](/reference/virtual-grid#callbacks).

- Column count comes from the grid's computed `grid-template-columns`.
- Gaps come from the grid's computed `column-gap` and `row-gap`.
- Item height comes from the probe. Without a probe, set `grid-auto-rows` on the grid.

::warning
Items with different heights in the same breakpoint are placed at the probe's height. They overlap or leave gaps.
::

## Scroll horizontally

Set `grid-auto-flow: column` and fix the rows with `grid-template-rows`. The grid then sets its `width` to the whole list, so the parent scrolls on the x axis.

```vue
<div class="h-[320px] overflow-x-auto">
  <VirtualGrid
    class="grid h-full grid-flow-col grid-rows-2 auto-cols-[200px] gap-4"
    :length="length"
    :page-size="40"
    :page-provider="pageProvider"
  />
</div>
```

Indexes fill each column top to bottom before the next column. [`getItemCellByIndex`](/reference/primitives#compute-rows-and-columns) follows the same order.

## Scroll to an item

Set `scrollTo` to an index. The grid scrolls its scroll parent to that item with `scrollBehavior`.
With `respectScrollToOnResize`, the grid scrolls back to that index after each resize, so a column change does not lose the item.
