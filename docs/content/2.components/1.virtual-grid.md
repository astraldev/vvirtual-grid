The `<VirtualGrid>` component is the core of this library. It handles the virtualization logic and rendering of your grid items.

## Props

| Name                       | Type                                 | Default                     | Description                                                                           |
| -------------------------- | ------------------------------------ | --------------------------- | ------------------------------------------------------------------------------------- |
| `length`                   | `number`{lang="ts-type"}             | **Required**                | Total number of items in the list.                                                    |
| `pageProvider`             | `Function`{lang="ts-type"}           | **Required**                | Async function that returns a page of items: `(pageNumber, pageSize) => Promise<T[]>` |
| `pageSize`                 | `number`{lang="ts-type"}             | **Required**                | Number of items per page.                                                             |
| `pageProviderDebounceTime` | `number`{lang="ts-type"}             | `0`{lang="ts-type"}         | Debounce window (ms) for `pageProvider` calls.                                        |
| `scrollTo`                 | `number`{lang="ts-type"}             | `undefined`{lang="ts-type"} | Scroll to a specific item index.                                                      |
| `respectScrollToOnResize`  | `boolean`{lang="ts-type"}            | `true`{lang="ts-type"}      | Snap to `scrollTo` when the container is resized.                                     |
| `scrollBehavior`           | `'smooth' \| 'auto'`{lang="ts-type"} | `'smooth'`{lang="ts-type"}  | The scroll behavior for `scrollTo`.                                                   |
| `tag`                      | `string`{lang="ts-type"}             | `'div'`{lang="ts-type"}     | HTML tag for the grid container.                                                      |
| `probeTag`                 | `string`{lang="ts-type"}             | `'div'`{lang="ts-type"}     | HTML tag for the probe element.                                                       |
| `getKey`                   | `Function`{lang="ts-type"}           | `undefined`{lang="ts-type"} | Custom key extractor: `(item) => string \| number`.                                   |

## Slots

::field-group
::field{name="default"}
The main slot used to render a loaded item.

**Properties:**

- `item`: The data item.
- `index`: Global index of the item.
- `style`: Style object (contains `transform` and `grid-area`) that **must** be applied to the item's root element.
  ::

::field{name="placeholder"}
Rendered when an item is in the buffer but not yet loaded.

**Properties:**

- `index`: Global index of the item.
- `style`: Style object that **must** be applied.
  ::

::field{name="probe"}
Used to measure item dimensions. Should render an element visually identical to your items.
::
::

::warning
If the `probe` slot is not provided, you must set a fixed height on `grid-template-rows` in your CSS.
::

## Exposed Properties

These properties are available via template refs:

::field-group
::field{name="allItems" type="Ref<T[]>"}
A `Ref` containing all currently cached/memoized items.
::

::field{name="ready" type="Ref<boolean>"}
A `Ref` that becomes `true` once the grid has performed its initial measurement.
::
::

## Sample usage

::tabs
:::tabs-item{icon="i-lucide-code" label="Example"}

```vue
<template>
  <VirtualGrid
    :length="1000"
    :pageSize="20"
    :pageProvider="fetchItems"
    class="grid grid-cols-[repeat(auto-fill,minmax(200px,1fr))] gap-4 h-[500px] overflow-y-auto"
  >
    <template #default="{ item, style }">
      <div
        :style="style"
        class="h-[250px] bg-white border border-gray-200 flex items-center justify-center rounded-lg shadow-sm"
      >
        {{ item.title }}
      </div>
    </template>

    <template #placeholder="{ style }">
      <div
        :style="style"
        class="h-[250px] bg-gray-50 border border-gray-100 animate-pulse rounded-lg"
      />
    </template>

    <template #probe>
      <div class="h-[250px]" />
    </template>
  </VirtualGrid>
</template>
```
