`vvirtual-grid` is a fork of [`vue-virtual-scroll-grid`](https://github.com/rocwang/vue-virtual-scroll-grid) by Roc Wang. The upstream package is published on npm as `vue-virtual-scroll-grid` up to version 1.11.0. The fork's first release follows upstream 1.11.0 and restarts the version numbers at 1.1.0, so the numbers do not continue from 1.11.0. Releases before the fork are recorded in the upstream repository.

The full history, with commit links, is in [`CHANGELOG.md`](https://github.com/astraldev/vvirtual-grid/blob/main/core/CHANGELOG.md).

## 1.2.0

- **Feature:** Added [`vvirtual-grid/primitives`](/reference/primitives), which return the rectangle, row and column of any item, rendered or not.
- **Feature:** Added the [`render`, `viewport-scroll` and `layout-change` events](/reference/virtual-grid#events) to `<VirtualGrid>`.
- **Feature:** Added the exposed `measurement` ref, which holds the flow, columns, rows, gaps and item size.
- **Fix:** Resolved `allItems`, `ready` and `measurement` being `undefined` on a template ref until the parent rendered again.
- **Performance:** 20 one-row scroll events through a list of 1,000,000 items take 0.40 ms, down from 1,530 ms in 1.1.6. See [Benchmarks](/reference/benchmarks).
- **Build:** The package is marked side-effect free.

## 1.1.6

- **Fix:** Resolved stale items after `length` changed. The grid reloads and recomputes the list.

## 1.1.5

- **Fix:** Resolved a corrupted list after `pageSize` changed at runtime.

## 1.1.4

- **Fix:** Resolved placeholders flickering while their page loaded.

## 1.1.2

- **Feature:** `pageProvider` can return an array. It no longer has to return a promise.
- **Fix:** Resolved package types conflicting with a user's build.
- **Fix:** Resolved peer dependency errors for Vue.

## 1.1.0

- **Feature:** Server-side rendering support.
- **Feature:** `createPageProvider` turns an array into a `pageProvider`.
