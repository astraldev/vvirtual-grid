`vvirtual-grid` is a fork of [`vue-virtual-scroll-grid`](https://github.com/rocwang/vue-virtual-scroll-grid) by Roc Wang. That package is published on npm as `vue-virtual-scroll-grid`, up to version 1.11.0. Releases before the fork are recorded in that repository. This changelog starts at the fork, with 1.1.x.

The full history, with commit links, is in [`CHANGELOG.md`](https://github.com/astraldev/vvirtual-grid/blob/main/core/CHANGELOG.md).

## 1.2.0

- **Feature:** Added [`vvirtual-grid/primitives`](/reference/primitives), which return the rectangle, row and column of any item, rendered or not. Each primitive reads and writes a query object that you create once and reuse.
- **Feature:** Added the [`render`, `viewport-scroll` and `layout-change` events](/reference/virtual-grid#events) to `<VirtualGrid>`.
- **Feature:** Added the exposed `measurement` ref, which holds the flow, columns, rows, gaps and item size.
- **Fix:** Resolved `allItems`, `ready` and `measurement` being `undefined` on a template ref until the parent component rendered again. They are set on the first render.
- **Performance:** Scrolling and starting take less time than in 1.1.6, measured on a list of 1,000,000 items. See [Benchmarks](/reference/benchmarks).
  - 20 scroll events of one row each: 0.40 ms instead of 1,530 ms. That is 99.97% less time, or about 3,800 times faster.
  - 20 scroll events of 2px each: 0.004 ms instead of 0.017 ms. That is 76% less time, or about 4 times faster.
  - Starting the grid: 0.82 ms instead of 44 ms. That is 98% less time, or about 54 times faster.
- **Build:** The package is marked side-effect free.

## 1.1.6

- **Fix:** Resolved stale items after `length` changed. The grid reloads and recomputes the list.

## 1.1.5

- **Fix:** Resolved a corrupted list after `pageSize` changed at runtime.

## 1.1.4

- **Fix:** Resolved placeholders flickering while their page loaded.

## 1.1.2

- **Feature:** `pageProvider` can return an array. It no longer has to return a promise.
- **Fix:** Resolved package types conflicting with a user's build.
- **Fix:** Resolved peer dependency errors for Vue.

## 1.1.0

- **Feature:** Server-side rendering support.
- **Feature:** `createPageProvider` turns an array into a `pageProvider`.
