Each grid on this page holds 10,000 items and shows one of the ARIA patterns from the [accessibility guide](/guides/accessibility). Each demo's source link opens its component.

## List with item positions

The grid has `role="list"`, and each item has `role="listitem"`, `aria-setsize` and `aria-posinset`.

::aria-list-demo
::

Check it:

1. Scroll to the middle of the list, then move the screen reader cursor onto an item. The announced position matches the item's number, for example 4,200 of 10,000.
2. Scroll the grid and select an item again. The announced position follows the item, not its place among the rendered elements.

Build it with [Add list roles](/guides/accessibility#add-list-roles) and [Set the size and position of each item](/guides/accessibility#set-the-size-and-position-of-each-item).

[Source: AriaListDemo.vue](https://github.com/astraldev/vvirtual-grid/blob/main/docs/app/components/content/AriaListDemo.vue)

## Listbox with a selected option

The grid has `role="listbox"` and an `aria-label`, and each item is an `option` with `aria-selected`.

::aria-listbox-demo
::

Check it:

1. Click an option. Its ring appears, and its `aria-selected` changes to `true` in the Elements panel of the browser's developer tools.
2. With a screen reader running, move its cursor onto the option and listen for "selected".

::warning
This demo selects with the mouse only. Clicking an option does not move focus, so a keyboard user cannot select one here. To make options focusable, use the pattern from [Keyboard navigation](#keyboard-navigation).
::

Build it with the [listbox and option roles](/reference/aria-patterns#list-and-listbox).

[Source: AriaListboxDemo.vue](https://github.com/astraldev/vvirtual-grid/blob/main/docs/app/components/content/AriaListboxDemo.vue)

## Busy placeholders

The page provider takes 1.5 seconds, so scrolling shows placeholders. Each placeholder has `aria-busy="true"` and keeps its position in the set.

::aria-busy-demo
::

Check it:

1. Scroll the grid. Gray placeholders appear before the items load.
2. Right-click a placeholder before it loads and choose Inspect. The Elements panel shows `aria-busy="true"` on the element, with the same `aria-posinset` the loaded item gets.
3. Wait 1.5 seconds. The grid replaces the placeholder with the item, which has no `aria-busy`.

::note
Screen readers differ in what they do with `aria-busy` on a list item. Some say "busy" and some say nothing, so move the screen reader cursor onto a placeholder and note what yours says.
::

Build it with [Mark placeholders as busy](/guides/accessibility#mark-placeholders-as-busy).

[Source: AriaBusyDemo.vue](https://github.com/astraldev/vvirtual-grid/blob/main/docs/app/components/content/AriaBusyDemo.vue)

## Keyboard navigation

Press Tab to enter the grid, then use the arrow keys. The focus ring follows the focused item. The grid scrolls only when the item would leave the view, and only far enough to show it.

::aria-keyboard-demo
::

Check it:

1. Press Tab until the focus reaches the grid. The first item has a focus ring.
2. Press the arrow keys. The focus moves one item or one row in that direction.
3. Hold the down arrow with a screen reader running. The grid scrolls, and the announced position keeps climbing.

Build it with [Keep the focused index in a ref](/guides/accessibility#keep-the-focused-index-in-a-ref), [Scroll to the new item and focus it](/guides/accessibility#scroll-to-the-new-item-and-focus-it), and [Listen for arrow keys on the grid](/guides/accessibility#listen-for-arrow-keys-on-the-grid).

[Source: AriaKeyboardDemo.vue](https://github.com/astraldev/vvirtual-grid/blob/main/docs/app/components/content/AriaKeyboardDemo.vue)

## Test it

A screen reader announces facts that hold for every item: its role, its name and its position, for example 4,200 of 10,000. The exact wording and the order vary by screen reader and browser, so check the facts and not a fixed sentence.

### macOS VoiceOver

1. Press Cmd + F5 to start VoiceOver.
2. Move through the page with the VO keys (Ctrl + Option) and the arrow keys.
3. Press VO + U to open the rotor and list the page's lists and items.

### Windows NVDA

[NVDA](https://www.nvaccess.org/download/) is a screen reader for Windows that costs nothing to download and use.

1. Install NVDA and start it.
2. Press Insert + F7 to open the elements list.
3. Close it, then use the arrow keys in browse mode to move through the items.

### Without a screen reader

- Chrome: open DevTools, then Elements, then the Accessibility pane. Select an item to see its computed role, name and position in set.
- Firefox: open DevTools and use the Accessibility inspector to see the same properties.

Scroll the grid and select an item again. The position in set must match the item's number, not its place among the rendered elements.

### Automated

The [axe DevTools](https://www.deque.com/axe/devtools/) extension and [`@axe-core/playwright`](https://www.npmjs.com/package/@axe-core/playwright) report missing or invalid roles. A Playwright test can also scroll the grid and read `aria-posinset` from the items that are rendered after the scroll:

```ts
import { test, expect } from "@playwright/test";

test("items keep their position after scrolling", async ({ page }) => {
  await page.goto("/examples/aria");
  const grid = page.locator('[role="list"]').first();
  await grid.evaluate((el) => {
    el.parentElement!.scrollTop = 20000;
  });

  const item = grid.locator("[aria-posinset]").first();
  await expect(item).toHaveAttribute("aria-setsize", "10000");
  const position = Number(await item.getAttribute("aria-posinset"));
  expect(position).toBeGreaterThan(100);
});
```
