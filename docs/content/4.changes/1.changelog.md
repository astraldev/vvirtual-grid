## 1.2.0

- **Feature:** [`vvirtual-grid/primitives`](/reference/primitives) returns the rectangle, row, column and element of any item, rendered or not. Each function takes one object of named arguments, which you can reuse between calls.
- **Feature:** `<VirtualGrid>` exposes [`measurement`](/reference/virtual-grid#exposed-refs) and accepts [`onRender`, `onViewportScroll` and `onLayoutChange`](/reference/virtual-grid#callbacks).
- **Fix:** Resolved `undefined` for `allItems`, `ready` and `measurement` on a template ref read before the parent rendered again.
- **Performance:** Scrolling a list of 1,000,000 items one row per event is about 3,000 times faster. See [Performance](/guides/performance).
- **Build:** The package is marked side-effect free. A bundle that imports only `VirtualGrid` contains none of the primitives.

## 1.1.6

- **Fix:** Resolved stale items after `length` changed. The grid now reloads and recomputes the list.

## 1.1.5

- **Fix:** Resolved a corrupted list after `pageSize` changed at runtime.

## 1.1.4

- **Fix:** Resolved placeholders flickering while their page loaded.
