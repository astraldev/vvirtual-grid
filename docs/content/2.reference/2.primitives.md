The primitives turn an index into a rectangle, a row and column, or an element.
The grid adds no roles, focus handling or overlays. You build those from these functions.

```vue
<script setup lang="ts">
import { useTemplateRef } from "vue";
import { VirtualGrid } from "vvirtual-grid/vue";
import { getItemViewportRect } from "vvirtual-grid/primitives";

// the <VirtualGrid> component instance, from ref="grid" below
const grid = useTemplateRef("grid");
const marker = useTemplateRef("marker");

// created once and reused, so a scroll event allocates nothing
const args = { root: null, index: 4200, layout: null, out: { x: 0, y: 0, width: 0, height: 0 } };

function onViewportScroll() {
  args.root = grid.value.$el; // the grid element
  args.layout = grid.value.measurement; // exposed by <VirtualGrid>
  if (args.layout && getItemViewportRect(args)) {
    marker.value.style.translate = `${args.out.x}px ${args.out.y}px`;
  }
}
</script>

<template>
  <div class="h-96 overflow-y-auto">
    <VirtualGrid ref="grid" :length="10000" :page-size="40" :page-provider="pageProvider" @viewport-scroll="onViewportScroll">
      <!-- slots -->
    </VirtualGrid>
  </div>
  <div ref="marker" style="position: fixed; inset: 0 auto auto 0" />
</template>
```

Item 4200 does not need to be rendered. Its rectangle comes from its index and the grid's measurement.

## Arguments

Every primitive takes one object. Create it once, change `index` or `target`, and call again.

::field-group
  ::field{name="root" type="Element"}
  The grid element, `grid.value.$el` on a template ref to `<VirtualGrid>`.
  ::

  ::field{name="layout" type="ItemLayout"}
  The grid's exposed [`measurement`](/reference/virtual-grid#exposed-refs). It is `undefined` before the first measurement, so check it first.
  ::

  ::field{name="out" type="ItemRect | ItemCell | GridDimensions"}
  An object the function writes into and returns. Reuse it, so the call allocates nothing.
  ::
::

The grid does not import `vvirtual-grid/primitives`. A bundle that imports none of them contains none of them.

## Compute positions

These work for every index, rendered or not. They do not check `index` against `length`.

### `getItemRectByIndex`

```ts
getItemRectByIndex({ index, layout, out }): ItemRect
```

Writes `x`, `y`, `width` and `height` in pixels, relative to the top-left corner of item 0. Arithmetic only, no DOM read.

### `getItemViewportRect`

```ts
getItemViewportRect({ root, index, layout, out }): boolean
```

Writes the rectangle relative to the viewport, in the same coordinates as `getBoundingClientRect()`.
It reads one element's layout. It returns `false` and leaves `out` unchanged when the grid has no rendered child.

## Compute rows and columns

With `grid-auto-flow: column`, indexes fill a column before moving to the next one. The row and column follow that order.

### `getItemCellByIndex`

```ts
getItemCellByIndex({ index, layout, out }): ItemCell
```

Writes the zero-based `row` and `column` of an item.

### `getIndexByCell`

```ts
getIndexByCell({ row, column, layout }): number
```

Returns the index at a zero-based row and column.

### `getGridDimensions`

```ts
getGridDimensions({ length, layout, out }): GridDimensions
```

Writes `rowCount` and `columnCount` for a list of `length` items.

## Find elements

These read the `data-index` attribute. Set `:data-index="index"` on the root element of the `default` and `placeholder` slots.

### `getItemElement`

```ts
getItemElement({ root, index }): HTMLElement | null
```

Returns the element rendering an item, or `null` when the item is not rendered.

### `getItemIndex`

```ts
getItemIndex({ root, target }): number
```

Returns the index of the item that contains `target`, such as `event.target`. Returns `-1` outside an item.

## Track rendered items

### `createItemTracker`

```ts
createItemTracker({ onBind, onUnbind }): (root: Element) => void
```

Returns a function to call from `onRender`. Each call compares the rendered items with the previous call.

::field-group
  ::field{name="onBind" type="(index: number, element: HTMLElement) => void"}
  An element started rendering `index`. It also fires when a loaded item replaces its placeholder.
  ::

  ::field{name="onUnbind" type="(index: number) => void"}
  No element renders `index` any more.
  ::
::

The tracker keeps two maps and swaps them, so a call allocates nothing after the first.

```ts
import { createItemTracker } from "vvirtual-grid/primitives";

const track = createItemTracker({
  onBind: (index, element) => element.toggleAttribute("aria-current", index === current),
  onUnbind: (index) => console.log("item left the DOM", index),
});
```

```vue
<VirtualGrid ref="grid" @render="track(grid.$el)" />
```

## Types

All exported from `vvirtual-grid/primitives`.

| Type | Fields |
| :-- | :-- |
| `ItemRect` | `x`, `y`, `width`, `height` |
| `ItemCell` | `row`, `column` |
| `GridDimensions` | `rowCount`, `columnCount` |
| `ItemLayout` | `flow`, `columns`, `rows`, `colGap`, `rowGap`, `itemWidthWithGap`, `itemHeightWithGap` |

The argument types are `ItemRectArgs`, `ItemViewportRectArgs`, `ItemCellArgs`, `IndexByCellArgs`, `GridDimensionsArgs`, `ItemElementArgs`, `ItemIndexArgs` and `ItemTrackerCallbacks`.
