## `createPageProvider`

Creates a `pageProvider` function from a local array or reactive data source.
Useful when your dataset is already available in memory and you don't need to fetch from an API.

### Type Definition

::field-group
  ::field{name="createPageProvider<T>" type="(data: MaybeRefOrGetter<T[]>) => (page: number, pageSize: number) => T[]"}
  Creates a pagination-based provider from an array or reactive data source.
  ::
::

### Usage

```ts
import { createPageProvider } from 'vvirtual-grid/vue'

const items = Array.from({ length: 1000 }, (_, i) => ({ id: i, title: `Item ${i}` }))

const pageProvider = createPageProvider(items)
```

::info
For Nuxt projects, use `useVirtualGridProvider` instead — it's automatically imported.
::

## Custom `pageProvider`

A `pageProvider` is a function that should be called by `<VirtualGrid>`
to get the data to render.

### Interface

::field-group
  ::field{name="PageProvider<T>" type="(page: number, pageSize: number) => T[] | Promise<T[]>"}
  The signature required for the `pageProvider` prop.
  ::

  ::field{name="page" type="number"}
  The current page index, starting from `0`.
  ::

  ::field{name="pageSize" type="number"}
  The number of items to return per page.
  ::
::

### Examples

#### Fetching from an API

```ts
const myPageProvider = async (page, pageSize) => {
  const response = await fetch(
    `https://api.example.com/items?offset=${page * pageSize}&limit=${pageSize}`
  )
  const data = await response.json()

  return data.items
}
```

#### Debouncing requests

To reduce the number of API calls when the user scrolls quickly, set the `pageProviderDebounceTime` prop on `<VirtualGrid>`.
It delays `pageProvider` calls until the user pauses.

### Best Practices

1. **Match the page size**: Return exactly `pageSize` items per page. For the last page, returning fewer items is fine.
2. **Handle errors gracefully**: Wrap your fetch in a `try/catch` to prevent rendering failures on network errors.
3. **Keep providers lightweight**: Avoid heavy transformations inside the provider; transform data before passing it in or use a computed ref.
