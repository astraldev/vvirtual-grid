`<VirtualGrid>` is the main component. It accepts a `pageProvider` and `length`, and takes care of all virtualization, pagination, and positioning internally.

## Props

| Name                       | Type                                 | Default                     | Description                                                                           |
| -------------------------- | ------------------------------------ | --------------------------- | ------------------------------------------------------------------------------------- |
| `length`                   | `number`{lang="ts-type"}             | **Required**                | Total number of items in the list.                                                    |
| `pageProvider`             | `Function`{lang="ts-type"}           | **Required**                | Async function that returns a page of items: `(pageNumber, pageSize) => Promise<T[]>` See [Utilities](/reference/utilities) for a local data helper. |
| `pageSize`                 | `number`{lang="ts-type"}             | **Required**                | Number of items per page.                                                             |
| `pageProviderDebounceTime` | `number`{lang="ts-type"}             | `0`{lang="ts-type"}         | Debounce window (ms) for `pageProvider` calls. Useful to reduce API requests during fast scrolling. |
| `scrollTo`                 | `number`{lang="ts-type"}             | `undefined`{lang="ts-type"} | Programmatically scroll to an item by index.                                          |
| `respectScrollToOnResize`  | `boolean`{lang="ts-type"}            | `true`{lang="ts-type"}      | Re-apply `scrollTo` when the container resizes.                                       |
| `scrollBehavior`           | `'smooth' \| 'auto'`{lang="ts-type"} | `'smooth'`{lang="ts-type"}  | Scroll animation style used when `scrollTo` changes.                                  |
| `tag`                      | `string`{lang="ts-type"}             | `'div'`{lang="ts-type"}     | HTML tag for the grid container element.                                              |
| `probeTag`                 | `string`{lang="ts-type"}             | `'div'`{lang="ts-type"}     | HTML tag for the hidden probe element.                                                |
| `getKey`                   | `Function`{lang="ts-type"}           | `undefined`{lang="ts-type"} | Custom key extractor: `(item) => string \| number`. Used for list reconciliation.     |

## Slots

::field-group
  ::field{name="default"}
  Renders a loaded item. The `style` prop **must** be applied to the item's root element for correct positioning.

  **Properties:**

  - `item`: The data item.
  - `index`: Global index of the item.
  - `style`: Style object (contains `transform` and `grid-area`) that **must** be applied to the item's root element.
  ::

  ::field{name="placeholder"}
  Renders while an item is loading. The `style` prop **must** be applied.

  **Properties:**

  - `index`: Global index of the item.
  - `style`: Style object that **must** be applied.  ::

  ::field{name="probe"}
  A hidden element used to measure item dimensions. Render something with the same size as your items.
  ::
::

::warning
If the `probe` slot is not provided, you must explicitly set a row height on the grid container via `grid-template-rows`.
::

## Exposed Properties

These properties are exposed by the component for reference purposes

::field-group
  ::field{name="allItems" type="Ref<T[]>"}
  A reactive ref containing all items the grid has loaded so far.
  ::

  ::field{name="ready" type="Ref<boolean>"}
  Becomes `true` after the grid completes its first measurement pass.
  ::
::

## Sample usage

::tabs
:::tabs-item{icon="i-lucide-code" label="Example"}

```vue
<template>
  <VirtualGrid
    :length="1000"
    :pageSize="20"
    :pageProvider="fetchItems"
    class="grid grid-cols-[repeat(auto-fill,minmax(200px,1fr))] gap-4 h-[500px] overflow-y-auto"
  >
    <template #default="{ item, style }">
      <div
        :style="style"
        class="h-[250px] bg-white border border-gray-200 flex items-center justify-center rounded-lg shadow-sm"
      >
        {{ item.title }}
      </div>
    </template>

    <template #placeholder="{ style }">
      <div
        :style="style"
        class="h-[250px] bg-gray-50 border border-gray-100 animate-pulse rounded-lg"
      />
    </template>

    <template #probe>
      <div class="h-[250px]" />
    </template>
  </VirtualGrid>
</template>
```
