`<VirtualGrid>` renders the items of a list that are in view and asks `pageProvider` for the pages they belong to.
Style it with CSS grid. Put it inside an element that scrolls.

::code-collapse
```vue
<template>
  <div class="h-[500px] overflow-y-auto">
    <VirtualGrid
      :length="1000"
      :page-size="20"
      :page-provider="fetchItems"
      class="grid grid-cols-[repeat(auto-fill,minmax(200px,1fr))] gap-4"
    >
      <template #default="{ item, style }">
        <div :style="style" class="h-[250px] rounded-lg border">{{ item.title }}</div>
      </template>

      <template #placeholder="{ style }">
        <div :style="style" class="h-[250px] rounded-lg bg-gray-100 animate-pulse" />
      </template>

      <template #probe>
        <div class="h-[250px]" />
      </template>
    </VirtualGrid>
  </div>
</template>
```
::

::warning
Do not set `overflow` or a fixed height on `<VirtualGrid>` itself. After computing, the grid sets its own height, overriding whatever you set, and the page scrolls instead of the grid.
::

## Props

| Name | Type | Default | Description |
| :-- | :-- | :-- | :-- |
| `length` | `number`{lang="ts-type"} | required | Total number of items in the list. |
| `pageProvider` | `PageProvider<T>`{lang="ts-type"} | required | Returns the items of one page. See [Utilities](/reference/utilities#write-your-own-pageprovider). |
| `pageSize` | `number`{lang="ts-type"} | required | Items per page passed to `pageProvider`. |
| **`pageProviderDebounceTime`** | `number`{lang="ts-type"} | `0`{lang="ts-type"} | Milliseconds to wait before calling `pageProvider`. Pages the user scrolls past during that time are never requested. For a provider that calls a network API, this is the most important setting. See [Performance](/guides/performance). |
| `scrollTo` | `number`{lang="ts-type"} | `undefined`{lang="ts-type"} | Index of the item to scroll to. Must be less than `length`. |
| `respectScrollToOnResize` | `boolean`{lang="ts-type"} | `true`{lang="ts-type"} | Scrolls to `scrollTo` again after the grid is resized. |
| `scrollBehavior` | `'smooth' \| 'auto'`{lang="ts-type"} | `'smooth'`{lang="ts-type"} | Passed to `scrollTo()` when `scrollTo` changes. |
| `tag` | `string`{lang="ts-type"} | `'div'`{lang="ts-type"} | Tag of the grid element. |
| `probeTag` | `string`{lang="ts-type"} | `'div'`{lang="ts-type"} | Tag of the hidden probe wrapper. |
| `getKey` | `(item: InternalItem) => string \| number`{lang="ts-type"} | `undefined`{lang="ts-type"} | Key used by Vue to match rendered items between updates. |

## Events

The grid emits three events. None of them carries a payload.
Inside a handler, read positions with the [primitives](/reference/primitives).

::field-group
  ::field{name="render"}
  The set of rendered items changed and the DOM was patched. Call an item tracker here.
  ::

  ::field{name="viewport-scroll"}
  A scroll parent of the grid scrolled, so every item moved on screen. It fires on every scroll event, so keep the handler cheap.
  ::

  ::field{name="layout-change"}
  The grid measured itself again, because the item size, the gap, the tracks or the flow changed.
  ::
::

```vue
<script setup lang="ts">
const onRender = () => console.log("rendered items changed");
const onViewportScroll = () => console.log("scrolled");
const onLayoutChange = () => console.log("measured again");
</script>

<template>
  <div class="h-96 overflow-y-auto">
    <VirtualGrid
      :length="1000"
      :page-size="20"
      :page-provider="fetchItems"
      @render="onRender"
      @viewport-scroll="onViewportScroll"
      @layout-change="onLayoutChange"
    />
  </div>
</template>
```

## Slots

::field-group
  ::field{name="default" type="{ item: T, index: number, style: StyleValue }"}
  Renders a loaded item. Bind `style` to the root element. It holds the item's position.
  ::

  ::field{name="placeholder" type="{ index: number, style: StyleValue }"}
  Renders an item whose page has not arrived. Bind `style` the same way.
  ::

  ::field{name="probe"}
  One hidden element with the size of an item. The grid measures it to place every item.
  ::
::

::warning
Without a `probe` slot, set the row height on the grid with `grid-template-rows` or `grid-auto-rows`, for example `200px`. The grid has no other way to learn the height of an item.
::

::tip
Set `:data-index="index"` on the root element of both item slots. With the attribute set, you can find an item's element or an event's item without a helper. See [Doing it with the DOM](/reference/primitives#doing-it-with-the-dom).
::

## Exposed values

Read these through a template ref on `<VirtualGrid>`. They are available on the first render.

```vue
<script setup lang="ts">
import { useTemplateRef } from "vue";

const grid = useTemplateRef("grid");
</script>

<template>
  <div class="h-96 overflow-y-auto">
    <VirtualGrid ref="grid" :length="1000" :page-size="20" :page-provider="fetchItems" />
  </div>
</template>
```

::field-group
  ::field{name="allItems" type="Ref<T[]>"}
  Every item loaded so far, by index.
  ::

  ::field{name="ready" type="Ref<boolean>"}
  `true` after the first measurement.
  ::

  ::field{name="measurement" type="Ref<ResizeMeasurement | undefined>"}
  The flow, tracks, gaps and item size the grid places items with. Pass it as `layout` to the [primitives](/reference/primitives). It is `undefined` until the grid is measured.
  ::
::
