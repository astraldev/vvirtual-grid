`<VirtualGrid>` reads items through a `pageProvider`. Use `createPageProvider` for data in memory, or write one for an API.

## `createPageProvider`

```ts
import { createPageProvider } from "vvirtual-grid/vue";

const items = ref(Array.from({ length: 1000 }, (_, i) => ({ id: i, title: `Item ${i}` })));
const pageProvider = createPageProvider(items);
```

::field-group
  ::field{name="createPageProvider<T>" type="(data: MaybeRefOrGetter<T[]>) => (page: number, pageSize: number) => T[]"}
  Returns a provider that slices `data` by page. It reads `data` on every call, so a ref or getter stays current.
  ::
::

::note
In Nuxt the same function is auto-imported as `useVirtualGridProvider`.
::

## Write your own `pageProvider`

```ts
const pageProvider = async (page: number, pageSize: number) => {
  const response = await fetch(`/api/items?offset=${page * pageSize}&limit=${pageSize}`);
  const data = await response.json();
  return data.items;
};
```

::field-group
  ::field{name="PageProvider<T>" type="(page: number, pageSize: number) => T[] | Promise<T[]>"}
  `page` starts at `0`. Return `pageSize` items, or fewer for the last page.
  ::
::

::tip
Set [`pageProviderDebounceTime`](/reference/virtual-grid#props) to skip requests for pages the user scrolls past.
::

::warning
The grid does not catch a rejected promise, and page loading stops after one. Catch errors inside the provider and return an empty array or cached items.
::
