**vvirtual-grid** is a reusable Vue 3 component designed to render massive lists (1,000+ items) as a grid with high performance.

It uses **virtual scrolling** (also known as windowing) to render only the items currently visible in the viewport, plus a small buffer. This keeps the number of DOM nodes constant and low, ensuring smooth scrolling even with huge datasets.

## Key Features

- **Virtual Scrolling**: Only render what's visible.
- **CSS Grid Integration**: Style your grid using standard CSS grid properties. The library respects your `grid-template-columns`, `gap`, etc.
- **Pagination Support**: Easily connect to a backend API using a page-based provider.
- **Placeholder Slots**: Provide a better UX by rendering placeholders while items are loading.
- **SSR Compatible**: Designed to work with Nuxt and Server-Side Rendering.
- **Responsive**: Adapts to container resizing and dynamic content sizes.

## How it Works

The component measures the size of its items using a "probe" element and then calculates which items should be in the buffer based on the current scroll position. It then offsets these items using CSS transforms to place them correctly within the grid structure.

This approach allows you to have a grid with:

1. Dynamic number of columns (using `auto-fill` or `auto-fit`).
2. Custom gaps.
3. Variable item sizes (though they should be consistent within a single view).
