**vvirtual-grid** is a reusable Vue 3 component designed to render massive lists (1,000+ items) as a grid with high performance.

It uses **virtual scrolling** (also known as windowing): only the items currently visible in the viewport, plus a small configurable buffer, are ever rendered. The number of DOM nodes stays fixed and low, regardless of the total dataset size.

## Key Features

- **Virtual Scrolling**: Only render what's visible in the viewport at any time.
- **CSS Grid Integration**: Style your layout using native CSS grid properties — `grid-template-columns`, `gap`, and more are fully respected.
- **Paginated Data Loading**: Connect to a remote API using a simple page-based provider function.
- **Placeholder Slots**: Render skeleton placeholders while items are still loading for a smooth user experience.
- **SSR Compatible**: Works out of the box with Nuxt and Server-Side Rendering.
- **Container-aware**: Automatically adapts when the container resizes.

## How it Works

::steps

### Measure item size

A hidden **probe** element is rendered with the same dimensions as your items. The component uses it to calculate item dimensions without rendering the full list.

### Calculate visible range

Based on the scroll position and the measured item size, the component determines which items fall within the viewport (plus a buffer).

### Fetch and render the buffer

Only items in the visible range are requested from your `pageProvider` and rendered. Items outside the range are discarded.

### Position with CSS transforms

Each rendered item is placed at its correct position using `style.transform` and `style.grid-area`. This avoids re-flow and keeps scrolling smooth.

::
