`vvirtual-grid` is a Vue 3 component that renders a long list as a CSS grid.
Only the items in the viewport, plus a buffer, are in the DOM.
A list of 1,000,000 items keeps the same few hundred elements as a list of 1,000.

::grid-demo
::

Scroll the grid. The element count under it stays flat while the numbers climb toward 999,999.

> Requires Vue 3.5 or later. Nuxt 3 and 4 are supported through the module.

## What you get

- [`<VirtualGrid>`](/reference/virtual-grid), the component.
- [`createPageProvider`](/reference/utilities), which turns an in-memory array into a `pageProvider`.
- [Primitives](/reference/primitives) in `vvirtual-grid/primitives`: item rectangles, rows and columns, element lookup and render tracking.

## How the grid places items

::steps
### It measures a probe

The `probe` slot renders one hidden element styled like your items.
The grid reads its size and the grid's `gap` and column tracks from it.

### It computes the window

The scroll offset and the item size give the visible items.
The grid renders twice that count, starting half a screen of items before the first visible one.

### It requests pages

The grid calls `pageProvider(page, pageSize)` for each page the window covers.
Items still loading render through the `placeholder` slot.

### It translates each item

Every rendered item gets a `style` with `grid-area: 1/1` and a `transform`.
All items share the first cell and move with `transform`, so scrolling triggers no reflow.
::
