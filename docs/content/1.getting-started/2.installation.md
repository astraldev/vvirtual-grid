Install the package, then import the component in Vue or register the module in Nuxt.

::code-group
```bash [pnpm]
pnpm add vvirtual-grid
```

```bash [npm]
npm install vvirtual-grid
```

```bash [bun]
bun add vvirtual-grid
```
::

## Use it in Vue

Import `VirtualGrid` where you render it.

```vue
<script setup>
import { VirtualGrid, createPageProvider } from "vvirtual-grid/vue";

const items = Array.from({ length: 1000 }, (_, i) => ({ id: i, name: `Item ${i}` }));
const pageProvider = createPageProvider(items);
</script>

<template>
  <VirtualGrid :length="items.length" :page-size="40" :page-provider="pageProvider">
    <template #default="{ item, style }">
      <div :style="style">{{ item.name }}</div>
    </template>
  </VirtualGrid>
</template>
```

To register it for the whole app, install the plugin.

```ts [main.ts]
import { createApp } from "vue";
import { VVirtualGridPlugin } from "vvirtual-grid/vue";
import App from "./App.vue";

createApp(App).use(VVirtualGridPlugin).mount("#app");
```

## Use it in Nuxt

Add the module to `nuxt.config.ts`.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ["vvirtual-grid/nuxt"],
});
```

The module auto-imports `<VirtualGrid>` and `useVirtualGridProvider`, which is `createPageProvider` under a Nuxt name.

::note
The [primitives](/reference/primitives) are not auto-imported. Import them from `vvirtual-grid/primitives`, so a page that does not use them does not ship them.
::
