## Installation

Install the package using your favorite package manager:

::code-group

```bash [pnpm]
pnpm add vvirtual-grid
```

```bash [npm]
npm install vvirtual-grid
```

```bash [bun]
bun add vvirtual-grid
```

::

## Integration

### Vue 3

You can import the `VirtualGrid` component directly in your Vue files:

```vue
<script setup>
import { VirtualGrid } from "vvirtual-grid/vue";
</script>

<template>
  <VirtualGrid :length="1000" :pageSize="40" :pageProvider="myPageProvider">
    <template #default="{ item, style }">
      <div :style="style">{{ item.name }}</div>
    </template>
  </VirtualGrid>
</template>
```

Alternatively, you can register it globally as a plugin:

```ts [main.ts]
import { createApp } from "vue";
import { VVirtualGridPlugin } from "vvirtual-grid/vue";
import App from "./App.vue";

const app = createApp(App);
app.use(VVirtualGridPlugin);
app.mount("#app");
```

### Nuxt

Add `vvirtual-grid/nuxt` to your `modules` in `nuxt.config.ts`. The `<VirtualGrid>` component will be automatically available in your templates.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ["vvirtual-grid/nuxt"],
});
```
